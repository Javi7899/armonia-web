# armonia-web

Páginas públicas de **Armonía**, la app para aprender música entendiéndola.

- `index.html` — página de soporte y preguntas frecuentes.
- `privacidad.html` — política de privacidad.

Aquí solo vive el sitio web. El código de la app no está en este repositorio.
